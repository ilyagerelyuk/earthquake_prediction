# Предсказание землетрясений на основе временных рядов
# Задача:
Оценивать риск сильного землетрясения (магнитуда > 6) в заданном регионе (Сахалин, Камчатка, Чукотка, частично Аляска) на следующий за периодом наблюдений день
# Реализация:
Подготовил временные ряды, выделив признаки энергии и места событий. Временной ряд был разбит на тренировочную и тестовую части в соотношении 9:1. В тестовую выборку попали 24 крупных землетрясения. Экспериментальным путем был выбран размер окна исторических данных в 200 дней. Для моделирования выбрал архитектуру LSTM с механизмом внимания, чтобы улавливать  долгосрочные зависимости и "важные" моменты в истории. Из-за сильного дисбаланса классов (редкие сильные землетрясения) использованы метрики precision и recall.
# Результаты:
Модель демонстрирует recall 0.54, что позволяет выявить более половины опасных событий, при precision 0.16. Данное соотношение существенно лучше случайного угадывания и считается адекватным для столь сложной прогнозной задачи.
